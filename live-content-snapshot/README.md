# תמונת מצב של התוכן החי

התוכן של תשע היחידות נשמר באתר (tikshuv.chepti.com) כאופציות וורדפרס `cpt_unit_content_1` עד `cpt_unit_content_9`, ונערך בעורך הקדמי. הקבצים כאן הם **גיבוי קריא** של האופציות האלה (JSON), ללא קשר לתיקיית `course-progress-tracker/units/*.html` — שם נשארו קבצי המקור הישנים, שמשמשים כגיבוי בלבד כשאין תוכן שמור.

- מקור האמת: האתר החי. הקבצים כאן מתעדכנים ידנית.
- התיקייה לא חלק מהתוסף ולא עולה לשרת בפריסה.
- ייצוא מחדש:
  `ssh -F "T:\.ssh\config" hostinger "cd /home/u630483490/public_html/tikshuv && wp option get cpt_unit_content_N --format=json"`
- שחזור (כתיבה לאתר! רק בכוונה): `wp option update cpt_unit_content_N --format=json < unit-N.json`

עודכן לאחרונה: 15.10.2026

## מבנה הפריטים (v4) - נוסף 15.11.2026

התיקייה `v4/` מכילה את התוכן במבנה החדש: פרק ← תת-פרק (עם כלל השלמה) ← פריט. באתר הוא נשמר באופציות נפרדות, `cpt_unit_v4_1` עד `cpt_unit_v4_10`, והאופציות הישנות (`cpt_unit_content_N`) נשארות ללא שינוי כגיבוי.

- ההמרה: `python -I tools/convert_v4.py` (קוראת את `unit-N.json` שבתיקייה הזו וכותבת ל-`v4/`).
- תצוגה מקומית בלי וורדפרס: `python -I tools/preview_v4.py`, ואז `course-preview-v4.html?unit=5`.
- אחרי ההפעלה, העריכה נעשית בעמוד היחידה עצמו ("מצב עריכה"), ולכן הקבצים ב-`v4/` הם תמונת מצב של רגע ההמרה בלבד. ייצוא עדכני: `wp option get cpt_unit_v4_N --format=json`.
- מתג ההפעלה לכל המשתלמות: האופציה `cpt_v4_enabled` (1/0). מנהלת רואה תצוגה מקדימה עם `?v4=1`.
