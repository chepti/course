# קורס הבינה המלאכותית למורים - הנחיות לסוכן AI

API לקריאה ולעריכה של קורס "בינה מלאכותית למורים" באתר חולמים תקשוב, בלי דפדפן ובלי התחברות בטופס.

- כתובת בסיס: `https://tikshuv.chepti.com/course-api/`
- תיאור עצמי מלא (בלי מפתח): `https://tikshuv.chepti.com/course-api/?action=help`
- אימות: כותרת `X-Key: <מפתח>` או פרמטר `?key=<מפתח>`. את המפתח מקבלים מבעלת האתר (ניהול האתר: התקדמות בקורס > גישה לסוכנים). המפתח לא מופיע בקוד ולא בקובץ הזה.

## המבנה

יחידה (unit, 1 עד 10) > פרק (chapter) > תת-פרק (group) > פריט (item).

לכל תת-פרק יש כלל השלמה (`rule`): `one` (מספיק פריט אחד), `all`, `optional` (רשות), או מספר. לומדת מקבלת 100% ביחידה כשעמדה בכלל של כל תת-פרק שאינו רשות, בלי לפתוח כל פריט.

## פעולות

| פעולה | שיטה | מה היא עושה |
|---|---|---|
| `help` | GET | החוזה המלא: פעולות, שדות, ערכים ודוגמאות. בלי מפתח. |
| `state` | GET | תמונת מצב קומפקטית. בלי `unit`: כל היחידות ברמת תת-פרק. עם `unit=N`: כולל פריטים, כל פריט כ-`[id, כותרת, סוג]`. |
| `get` | GET | תוכן מלא של פריט (או פתיח של תת-פרק / פרק). `unit`, ו-`id` או `match`, ו-`type` (item / group / chapter). |
| `progress` | GET | סיכום התקדמות הלומדים ביחידה. `detail=1` מוסיף שורה לכל לומד. |
| `ops` | POST | מערך פעולות עריכה בבקשה אחת, עם דיווח הצלחה או כשל לכל פעולה בנפרד. |

## פנייה לפי כותרת

בכל מקום שמקבל `id` אפשר לשלוח במקומו `{"match": "חלק מהכותרת"}`. החיפוש נעשה בנתיב המלא (פרק › תת-פרק › פריט). אם יש יותר מהתאמה אחת, הפעולה נכשלת ומחזירה `candidates` עם `id` לכל מועמד, ואז שולחים שוב עם ה-`id` המדויק.

## דוגמה

```bash
curl -s "https://tikshuv.chepti.com/course-api/?action=state&unit=5" -H "X-Key: <KEY>"
```

```bash
curl -s -X POST "https://tikshuv.chepti.com/course-api/?action=ops" -H "X-Key: <KEY>" -H "Content-Type: application/json" -d '{"ops":[{"op":"item_save","unit":5,"match":"קנבה קוד","title":"קנבה קוד"},{"op":"item_add","unit":5,"match":"משחקים ולומדות","title":"כלי חדש","html":"<p>הסבר</p>[video: https://youtu.be/XXXXXXXXXXX | הדגמה]"}]}'
```

## תוכן של פריט

HTML רגיל, ובתוכו אפשר לשלב:

- `[video: URL | כותרת]` - סרטון יוטיוב.
- `[prompt]טקסט[/prompt]` - תיבת פרומפט עם כפתור העתקה.
- `[canva: URL]` - הטמעת מצגת קנבה.
- `[done-button: טקסט]` - תיבת סיום למשימה.

כותרת הפריט נשמרת בנפרד מה-HTML, ולכן אין צורך לחזור עליה בתוכן.

## System prompt מוכן להדבקה

```
יש לך גישה ל-API של קורס הבינה המלאכותית למורים (חולמים תקשוב).
כתובת הבסיס: https://tikshuv.chepti.com/course-api/
המפתח: <KEY> (שולחים בכותרת X-Key בכל בקשה חוץ מ-help).
לפני כל דבר קרא את ?action=help כדי ללמוד את הפעולות והשדות.
לקריאת המבנה: action=state (ועם unit=N לפירוט פריטים). לתוכן מלא של פריט: action=get.
לשינויים: POST ל-action=ops עם {"ops":[...]}. אפשר לפנות ליעד עם match במקום id.
שינויים נכנסים לאתר החי מיד ומאות מורים לומדים בקורס, לכן:
- לפני מחיקה או שינוי גדול, הצג מה אתה עומד לעשות וחכה לאישור.
- לפני עריכת פריט, קרא אותו עם get ושנה רק את מה שהתבקש.
- כל התכנים בקורס צריכים להישאר חינמיים או freemium למורים.
```

אותו API זמין גם דרך `https://tikshuv.chepti.com/wp-admin/admin-ajax.php?action=cpt_api&do=<פעולה>`.
